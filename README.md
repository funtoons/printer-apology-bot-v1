One-line apology from an office printer to the people who keep jamming it,
feeding it cheap paper and swearing at it — entered in the make.fun
competition [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153).

## Entry

> Sorry I jammed on page 47 of 48. Your cheap paper tasted like cardboard, so I kept the last page for myself.

## Run

```sh
python3 main.py   # writes the entry to /output/entry.txt
```

Deterministic, offline, standard library only: two runs produce
byte-identical output.
